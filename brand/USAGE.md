# How to use the KC&C and mero logos

This page is for anyone who places a KC&C or mero logo: our team, partners, press and designers. The names and
logos are not licensed for other use (see `LICENSE`, section 2). Use them only to refer to KC&C or mero, or with
our written permission.

Always use the files in `brand/logos/` (or the `Logo` component of `@kcc/design`). Do not redraw, retype or trace a
logo. Construction details are in `brand/README.md`.

## The logos

| Logo | File | Use |
|---|---|---|
| KC&C lockup | `kcc-lockup-*.svg` | Default. Wordmark, rule and "Credit & Collateral" |
| KC&C wordmark | `kcc-wordmark-*.svg` | Narrow spaces: navigation bars, running headers |
| KC&C monogram | `kcc-monogram-*.svg` | Documents and social cards: framed "KC" |
| KC&C icon | `kcc-icon-*.svg`, `icons/kcc/` | Favicons and app icons only |
| mero lockup | `mero-lockup-*.svg` | Default for mero |
| mero wordmark | `mero-wordmark-*.svg` | Narrow spaces in the mero app |
| mero mark | `mero-mark-*.svg`, `icons/mero/` | Favicons and app icons only |

## Clear space

Keep an empty space around the logo on every side. Nothing goes inside it: no text, no edge of the page, no other
logo, no busy image.

- The clear space is **21 units** at the logo's reference size (the size in the SVG file), on every side. Scale it
  with the logo.
- A quick measure: for the KC&C lockup, the clear space is about **30%** of the logo's height (21 / 71). For the
  monogram, icon and mero mark, it is about **24%** of the side (21 / 89).

## Minimum sizes

Below these sizes the letters close up. Use a smaller logo version instead, or leave the logo out.

| Logo | Smallest size on screen | Smallest size in print |
|---|---|---|
| KC&C lockup | 55 px high | 18 mm high |
| KC&C wordmark | 13 px cap height | 4.3 mm cap height |
| KC&C monogram | 24 px | 8 mm |
| KC&C icon, mero mark | 16 px | 5.2 mm |
| mero lockup | 34 px high | 11 mm high |

## Colour versions

Each logo has four versions. Use the version that matches the background. No other colour is allowed.

| Version | Logo colour | Use it on |
|---|---|---|
| `primary` | Ink `#141414`; the mero mark in heavy green | Paper `#F3EFE4`, white, or a light plain background |
| `ink` | Ink `#141414`, one colour | One-colour print, fax, stamps, engraving |
| `reversed-green` | Paper `#F3EFE4` | Heavy green (`--kc-green-800`) |
| `reversed-dark` | Paper `#F3EFE4` | Dark paper (the dark theme), or a dark plain background |

The marks are one path with the letter cut out. The letter shows the background behind the logo, so place the logo
only on a plain background with enough contrast (at least 3:1 against the logo colour).

## Do

- Use the files as they are. Scale them in proportion.
- Keep the clear space and the minimum size.
- Use the colour version that matches the background.
- Use the icon or mark only where a square is needed (favicons, app icons, avatars).

## Do not

- Stretch, squash, rotate, slant or crop a logo.
- Change its colour, or use a colour that is not in the table above.
- Add a shadow, glow, outline, gradient or 3D effect.
- Put a mark in a circle, a coin or a badge.
- Place a logo on a photograph, a pattern or a background with low contrast.
- Set "KC&C" or "mero" in another font, or rebuild the logo from a font.
- Put words, a tagline or another logo inside the clear space.
- Use the logo as part of your own name, logo, product name or domain name.

The Brand page of the playground (`npm run dev`, then `/brand`) shows each case.

## Co-branding

**Never put a KC&C or mero logo in a client's colour palette, or next to a client's logo, without written
permission from both KC&C and the client.**

- A KC&C document always uses the KC&C look: paper, ink, the KC&C logo. It does not take on a client's colours,
  fonts or layout, so that it never looks like the client's own material.
- A joint document (for example a joint report after a pilot) needs written permission from both sides before it
  uses both logos. Then put the two logos side by side, at the same visual height, separated by at least the clear
  space, each in its own colours.
- Do not name a client, partner or user in public material without their written consent.

## Questions

For permission to use a logo, or for a version that is not here, ask KC&C. Do not make your own version.
